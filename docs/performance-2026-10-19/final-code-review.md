## Resolved edge and remaining limits

This review identified a source-derived race possibility in the initial candidate: a visitor returning from `/training` could skip the first intro and immediately replay it while `introReady` was still false, briefly disabling/re-enabling the photo effect while an earlier decoded pair's animation was pending. Root resolved this by adding `setIntroReady(true)` in the `consumeReturnToHome()` branch (`BentoHome.tsx:88–91`). I read the updated branch and verified the photo eligibility predicate now remains true through this replay path. Root is rebuilding and exercising the path in Umbra. No source edits were made by this review worker.

The 8-second activity timeout is an explicit availability tradeoff: a slower cold upstream now leaves this visit's activity fallback, while the portfolio stays responsive. Browser abort does not itself cancel the upstream server fetch. Upstream timeouts, distributed request coalescing, retries, and privacy behavior beyond the unchanged public source function are outside these edits.
